# ReGrip 디자인 선택용 HTML 목업

**최종 결정 · 2026-09-05:** 사용자는 “지금 디자인 유지하자 맨처음꺼 바꾸지마!”라고 확정했다. 실서비스는 기존 디자인을 유지한다. 아래 A/B/C는 참고용 목업으로만 남기며, 신규 테마를 본편에 적용하지 않는다. 목업에서 누른 선택 버튼 역시 실서비스 적용 권한이나 최종 결정의 변경을 의미하지 않는다.

Windows Chrome/Edge에서 손 압력 훈련을 처음 접하는 사용자를 위한 세 가지 독립 방향. 실제 제품을 바꾸기 전에 화면 구조와 톤을 고르는 용도다. 동일한 예시 데이터와 기능을 사용하며 선택값은 `regrip_design_choice`에만 저장한다.

## 레퍼런스 잠금

| 방향 | 주 레퍼런스 | 보존할 특징 | ReGrip에 맞춘 구조 |
|---|---|---|---|
| A 차분한 블루 | [Refero Apple](https://styles.refero.design/style/aecac5da-f397-4ddf-b71f-de1efc434cb8) | 흰색과 연회색, 17px 본문, 얇은 구분선, 둥근 액션 버튼, 행동에만 쓰는 블루 | 상단 탐색, 중앙 인사말, 추천 게임을 먼저 보여주는 넓은 화면 |
| B 친근한 세이지 | [Astryx](https://github.com/facebook/astryx)의 테마 구조 + [Refero Duolingo](https://styles.refero.design/style/7088d695-362b-4e09-b325-fa8136d4f350)의 단계형 진행 | 세이지 색의 편안한 표면, 굵은 보조 버튼, 작고 명확한 완료 피드백 | 센서 준비→짧은 연습→기록의 세 단계. 오른쪽에는 주간 진행 표시 |
| C 선명한 라벤더 | [Refero Phantom](https://styles.refero.design/style/6144c3ae-fc57-4efe-b6ed-2b5eab2dc108) | 짙은 보라 구조, 라벤더 표면, 캡슐 버튼, 낮은 글자 굵기, 색 영역의 대비 | 세로 탐색 레일, 큰 게임 영역, 짙은 주간 기록 영역과 게임 목록 |

A의 블루는 주요 행동에만 사용한다. B는 Duolingo의 마스코트·형광 초록을 가져오지 않고 진행 구조와 버튼 촉감만 차용한다. C는 라벤더와 짙은 보라의 면을 사용하며 장식용 그라데이션을 넣지 않는다. 세 옵션의 색·레이아웃을 평균 내지 않는다.

## 공통 결정

- 사용자 요청에 따라 생성 이미지 대신 HTML을 제공한다. 구름·풍선·목표 구간은 실제 제품 장면을 설명하는 코드 기반 SVG다. 사진이나 제품 실물의 대체물이 아니다.
- 외부 CDN과 폰트 다운로드 없이 시스템 한국어 폰트를 사용한다. 세 가지 테마 토큰은 비교 목업용이며 Astryx React 컴포넌트를 사용했다고 주장하지 않는다.
- 비교 도구는 제품 화면 밖에 놓는다. A/B/C 전환, 데스크톱·390px 모바일 보기, 선택 버튼을 제공한다.
- 오늘·훈련·기록 탐색, 예시 센서 연결, 2단계 보정, 슬라이더로 조작하는 풍선 연습, 일시정지·재연습이 동작한다.
- 실제 BLE/API/운동 기록을 호출하지 않는다. 모든 화면 상단에 `디자인 미리보기 · 예시 데이터`를 표시한다. 목업의 20초 게임은 조작 흐름 검토용이며 실서비스 물리 엔진의 복제본이 아니다.
- 훈련 기록에는 센서·시뮬레이션·출처 미확인 예시를 명시한다. 개선 효과나 사용자 측정 결과를 주장하지 않는다.
- 키보드 focus-visible, 명시적 슬라이더 label, dialog, 상태 알림, reduced-motion 및 container query를 적용한다.

## 열기 및 검증

- `design-review/index.html?theme=a`, `?theme=b`, `?theme=c`로 직접 진입한다. `&screen=training` 또는 `&screen=records`로 화면을 지정할 수 있다.
- `&device=mobile`은 390px 컨테이너를 사용한다. 좁은 실제 창에서는 가용 폭에 맞춰 축소한다.
- 2026-09-05: JavaScript 문법과 로컬 자산 경로, UTF-8 대체 문자 부재를 확인했다. Node VM의 DOM 경계 모형으로 3개 방향 × 3개 화면 생성, 모의 연결·보정 완료, 연습 시작·성공·재연습을 검증했다. 실제 브라우저 렌더·스크린샷은 현재 이용 가능한 브라우저 세션이 없어 미검증이다. 선택 전에 1440px/390px에서 화면 밀도, 한국어 줄바꿈, 대화상자, 대비와 포커스 이동을 확인해야 한다.
- 설치된 Astryx CLI의 `docs layout`, `build "Hand pressure training dashboard with beginner onboarding, game preview and session records"`를 실행해 화면 구역·탐색·진행 단계 권고를 확인했다. React 구성요소 구현이 아닌 사용자가 요청한 독립 HTML 선택안에 참고했다.

Refero 스킬의 research-first, reference lock, visual workflow, craft-details를 적용했다. 요청받은 HTML 선택안은 참고 자료로 보존한다. 사용자의 최종 선택은 기존 실서비스 디자인 유지이며, 새 디자인 적용 작업은 진행하지 않는다.
